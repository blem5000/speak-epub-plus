## Findings

All findings were derived from the diff and re-verified against primary sources before routing.

### Build / i18n (highest impact)

- **[HIGH] fix now — `npm run build` broken by an unused import introduced in `c700be5`.** `src/App.announcer.test.tsx:3` imports `userEvent`, never used; `tsconfig.json` sets `noUnusedLocals: true` and build is `tsc && vite build`, so `tsc` fails with TS6133. Verified by running tsc — this is the only tsc error in the repo. **Already tracked as `epic-2-retro-item-18` in sprint-status — not duplicated here.**
- **[HIGH] fix now — dead i18n keys, hardcoded Polish alerts rendered instead.** `t("toast.ban")` and `t("ffmpeg.missing")` exist in both locales (`en.json:72-73`, `pl.json:72-73`) but are never called; `App.tsx:467` and `:480` render literal Polish strings (`Przerwa — wykryto ograniczenie…`, `FFmpeg nie znaleziono…`). An English-locale user sees Polish ban/FFmpeg alerts. Verified by direct read.
- **[MEDIUM] fix now — broken i18n ternary.** `FiltersWindow.tsx:105` renders `{t("preview.original") ? "Zamknij" : "Close"}` — `t()` never returns falsy (`i18n/index.ts:46-47` returns the key itself), so this always renders Polish "Zamknij".
- **[MEDIUM] fix now — hardcoded strings violate story 4-2's "no hardcoded strings" AC.** `Settings.tsx:293,330,364` hardcode English toasts (`voice must be non-empty`, `invalid rate pattern …`); `Queue.tsx:172` (`{n} parts`), `Queue.tsx:220` (`aria-label="Log pobierania"`), `App.tsx:747` (`Pobieranie…`/`Start`); `Preview.tsx:340-346` hardcodes the Polish removed-count chip while the dedicated `filters.chip` key sits unused in both locales (`en.json:69`, `pl.json:69`).
- **[LOW] accept as-is (flag) — `t(key) || "literal"` dead-fallback pattern cargo-culted.** `FiltersWindow.tsx:77,84,88`, `Filters.tsx:40,58,106-168`, `App.tsx:414-415` — unreachable since `t()` returns the key; `t(..., { defaultValue })` at `App.tsx:687` uses a param `t()` has no semantics for.
