- (decision) Brownfield ratification: reuse speak.py split_text_for_tts max_chars 3500 sentence-boundary chunking, PartJob global parallel queue (parallel 2-3, 5 retries backoff), FFmpeg concat + M4B markers, spine order numbering, <100 chars skip. Prevents reimplementing proven truncation-safe pipeline.
- (constraint) Existing stack: Python 3.10+, ebooklib 0.20, BeautifulSoup4 4.14.3, lxml 6.0.2, edge-tts 7.2.8 verified 2026-03-22, FFmpeg/ffprobe on PATH for M4B. Must keep venv at Speak-EPUB-1.0.0/venv per AGENTS.md

- (decision) AD-1 Dependency direction: GUI (Tauri) -> Core API -> Adapters & Pipeline stages. Adapters never import GUI or pipeline internals; pipeline never imports adapters directly — only via port interface listChapters/fetchChapter/search/getSelectors. Prevents circular drift.
- (decision) AD-2 Filtering stage: filter phrases (plain contains + regex) applied at EPUB build (not at fetch, not at TTS). Guarantees EPUB clean = audio clean automatically, single source of truth, prevents double-apply divergence.
- (decision) AD-3 Politeness ownership: Fetcher owns delay/jitter (3-5s default, 10s safe) + adaptive backoff on 429 + jitter; Core orchestrator increments delay, never GUI. Cache raw HTML per chapter to enable conditional resume. Prevents aggressive parallel scrapers causing bans.
- (decision) AD-4 Sidecar contract: Tauri Rust backend spawns Python sidecar (Speak-EPUB-1.0.0/venv/Scripts/python.exe -m core) via tauri-plugin-shell, communicates via JSON-RPC over stdin/stdout [ASSUMPTION]. No direct FS pollution by GUI; all file paths resolved by core. Prevents GUI bypassing pipeline invariants.
- (decision) AD-5 State ownership: Core owns chapter list + raw cache + cleaned text + EPUB manifest + PartJob queue + progress events. Adapters own selectors + heuristic fallback; GUI is stateless view + persisted config mirror (voice/rate/parallel/chunk/retries/delay/keeps). Prevents split ownership of chapter index.
- (decision) AD-6 Progress events: single event bus (Tauri emit -> frontend listen) with typed events: chapterStatus, partStatus, logLine, throttleChanged, done. Polling forbidden; resume badge derived from cache diff. Prevents inconsistent progress from two sources.
- (decision) AD-7 Content boundary: per-adapter start/end CSS selectors + heuristic fallback (article/div.chapter-content) + preview pane allows manual override stored per-adapter overlay. Heuristic never auto-overwrites adapter selectors without user confirm. Prevents silent chrome leakage into EPUB.
- (decision) AD-8 EPUB as intermediate invariant: Build EPUB first, validate via epubcheck clean as gate, then feed EPUB into TTS pipeline via extract_chapters (same path as CLI). No TTS from raw HTML. Prevents divergent text sources between EPUB and audio.
- (decision) AD-9 Resume semantics: bounded range (e.g., 20-100) -> fetch only missing chapters using cache diff [ASSUMPTION: cache keyed by URL+hash]; open-ended to-end -> re-validate chapter list to detect new chapters, then fetch missing. Prevents stale list or duplicate fetch.
- (decision) AD-10 Config persistence: single local JSON (tauri-plugin-store) mirrors CLI flags: voice, rate, parallel, chunk-size, retries, scrapeDelay, safeMode, keepEPUB/MP3/M4B, filters. GUI writes, core reads on start. No env vars or registry [ASSUMPTION]. Prevents drift between CLI and GUI.
